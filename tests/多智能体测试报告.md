## 5. 重点案例：小红书种草笔记

用户输入：

> 帮我写一篇 声海 X1 真无线蓝牙耳机 的开箱种草笔记，学生党用

输出结果：

- 7 个固定段落齐全：`【标题备选】【正文】【商品信息】【商品实拍】【配图建议】【标签】【数据说明】`
- 【商品信息】由系统用工具返回的真实数据确定性生成：
  - 商品：声海 X1 真无线蓝牙耳机
  - 价格：¥299.00（原价 ¥399.00）
  - 评分：4.6 分｜库存：120 件
  - 核心规格：续航 6h+24h、蓝牙 5.3、佩戴方式 半入耳
  - 优惠：FULL200 全场满200减30（满 ¥200 立减 ¥30.00），券后 ¥269.00
- 【商品实拍】输出可渲染的真实图片 Markdown，并按 `match_level` 如实标注
  （本例检索到的是同品牌其他型号，因此标注为「品牌同系列参考图（非该型号实拍）」）
- 【数据说明】标注了哪些来自实时检索、哪些是主观体验、哪些未获取到

## 6. 防幻觉验证记录

种草文案是幻觉高发区，本轮联调中实际抓到并修掉的问题：

| 现象（修复前） | 修复手段 |
| --- | --- |
| 编造"单只耳机重量 3.8g""查了官网参数" | 提示词铁律：只允许引用工具返回的 specs/description |
| 编造"实测充了 4 次""15 分钟回血 30%" | 禁止编造测试过程与量化实测 |
| 原价写成 ¥129（真实为 ¥159） | 工具调用记录抽取商品 JSON，确定性重写【商品信息】 |
| 反向推断"没有无线充电/没有数显屏" | 校对规则 + 直接删除，不插入占位句 |
| 编造"附赠三对硅胶耳翼""呼吸灯""触控灵敏" | 校对规则 + 确定性句子级过滤（`scrub_unsupported_details`） |
| 把同品牌 PX210BT 的图标成"X1 实拍" | 图片 `match_level` 按标题与型号 token 实际关系判定 |
